Android Malware Detection

Python · scikit-learn · pandas · NumPy · Matplotlib · imbalanced-learn · Jupyter

A binary classifier over the TUANDROMD dataset — 4,465 Android applications, 241 permission-based features — comparing logistic regression against a random forest. I corrected the class imbalance with SMOTEN, split with stratified sampling, and tuned through cross-validated grid search. Evaluated on recall and F1 rather than accuracy alone, because a missed malware sample costs more than a false alarm: roughly 99.7% accuracy with 100% recall on the held-out set.
